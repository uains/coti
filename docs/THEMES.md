# 主题设计

## Feishu（默认）

参考飞书文档的内容阅读风格：

| 语义 | 颜色 |
|---|---|
| 页面背景 | `#FFFFFF` |
| 标题栏 / 状态栏 | `#FFFFFF` |
| 正文 | `#1F2329` |
| 标题 | `#1F2329` |
| 次要文字 | `#646A73` |
| 弱化文字 | `#8F959E` |
| 选中背景 | `#D6E4FF` |
| 光标 / 强调 | `#3370FF` |
| 代码块背景 | `#F5F6F7` |
| 引用背景 | `#F7F8FA` |
| 引用竖线 | `#D0D3D6` |
| 边框 / 表格线 | `#E5E6EB` |
| 表头背景 | `#F5F6F7` |
| 列表标记 | `#646A73` |

排版：

- 正文字号 15，行高 26。
- 标题层级 1.8 / 1.5 / 1.25 / 1.15 / 1.1 / 1.05。
- 内容最大宽度 800，左右留白 32。
- 块间距 10，代码块内边距 12。
- 引用缩进 18，列表缩进 22。
- 图片默认高度 180。

## 其他主题

- `ink`：深色。
- `paper`：浅色。
- `contrast`：高对比度。

主题切换：标题栏调色板按钮或 `Ctrl+Shift+T`。切换主题时会同步字体/行高指标。
